TypeScript Web API Glossary

这门课讲怎么用 TypeScript 写一个能上线的 Web API：从 HTTP 报文、路由、参数校验一路做到数据库与部署。

Terms

端点 (endpoint):
一个「方法 + 路径」的组合，是客户端能调用的最小单位，例如 POST /orders。
Avoid: 接口、路由地址（"接口"太泛，"路由"指的是匹配规则那一层）

中间件 (middleware):
排在处理函数之前、能读到请求并决定继续或提前返回的函数，用来做日志、鉴权、错误兜底。
Avoid: 拦截器、过滤器

幂等 (idempotent):
同一个请求重复发多次，服务端最终状态与发一次相同。PUT 与 DELETE 一般设计成幂等，POST 不保证。
Avoid: 可重试（那是"重试安全"，是它的结果不是它的定义）

参数校验 (validation):
在进入业务逻辑前，把入参检查成可信的形状；失败要返回明确的 4xx 与哪一项不合法。
Avoid: 类型检查（那是编译期的事）

迁移 (migration):
用可重放的脚本管理表结构变更，让"数据库当前长什么样"能从代码推出来。
Avoid: 建表脚本、DDL（后者是手段，不是这个概念）
